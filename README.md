# AK Prime Holdings

A premium, highly interactive dark-themed platform coordinating strategic capital advisory guidance and web application engineering systems.

## Features

- **Compounding Growth Visualizer**: Interactive investment growth simulator with a slowly drawing CAGR curve and a real-time ticking wealth compounding counter.
- **Market Insight Center**: Live simulated stock ticker (RELIANCE, TCS, HDFCBANK) that updates both price percentages and SVG sparkline paths dynamically in real-time.
- **Premium Tech Aesthetics**: Custom vector SVG icons, a subtle engineering grid background texture, and an interactive mouse-glow spotlight overlay.
- **Buttery Smooth Performance**: 60fps throttled scroll listeners powered by `requestAnimationFrame` for high-performance layout rendering and active nav highlights.
- **Fully Responsive**: Designed to scale flawlessly from high-res monitors down to mobile viewports under 768px.

## Project Structure

- `index.html`: The core single-page application containing styles, vector SVG assets, and interactive simulation scripts.
- `.nojekyll`: Disables Jekyll processing on GitHub Pages to ensure fast, static asset routing.
